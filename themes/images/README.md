# 角色背景图

当前使用的图片：

- `hutao.png` — 胡桃背景图
- `furina.png` — 芙宁娜背景图

CSS 已经通过 `--bg-image` 引用了这两个文件：

```css
/* hutao.css */
--bg-image: url("./images/hutao.png");

/* furina.css */
--bg-image: url("./images/furina.png");
```

这些图片也已经复制到 Web 应用的静态目录：

```text
apps/web/public/themes/hutao.png
apps/web/public/themes/furina.png
```
